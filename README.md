# Corredor Infinito

Endless runner para navegador.

## Cómo jugar

1. Abre `index.html` en el navegador.
2. Toca o haz clic para **saltar** (no hace falta la barra espaciadora).
3. Desliza hacia abajo, mantén el dedo en la parte baja de la pantalla, o usa **S / ↓** para **agacharte**.
4. Pasa cajas bajas saltando y vigas altas deslizándote.
5. Las rampas amarillas dan un impulso de velocidad.
6. Encadena obstáculos para subir el **combo**.
7. El récord se guarda en `localStorage`.

## Controles

| Acción | Entrada |
| --- | --- |
| Saltar | Toque / clic / flecha arriba / W |
| Deslizar | Swipe abajo / zona inferior / S / flecha abajo |
| Reiniciar | Botón en la pantalla de fin |
